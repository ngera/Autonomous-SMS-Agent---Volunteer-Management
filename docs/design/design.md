# Design — Booking System (current-state baseline)

Descriptive snapshot of the UI design as it exists today (2026-05-23, post Notion-theme swap), extracted from the frontend source. **Not prescriptive.** When the codebase changes, regenerate this file. The companion migration doc (`migration-plan.md`) tracks the Stream 1 → Stream 2 work.

Generated by reading: `frontend/src/index.css`, `frontend/components.json`, `frontend/package.json`, `frontend/src/components/ui/*`, `frontend/src/components/layout/*`.

---

## Overview

The booking system is an **admin panel** — utilitarian, dense, data-first. No marketing surfaces; every screen is an authenticated view: dashboard, calendar, volunteers, campaigns, conversations, settings. The aesthetic adopted a **Notion-flavored theme** in May 2026: signature purple primary (Notion's recognizable CTA color), Inter typography, 8px-rounded buttons at 40px tall, 12px-rounded cards with hairline borders. Brand chromatic identity is now `oklch(0.55 0.22 285)` purple instead of the older grayscale-only palette.

The layout is a persistent left sidebar + top header + main content area pattern. Sidebar uses a separate token namespace (`--sidebar-*`) and renders with a slightly-warmer-than-canvas off-white background. Cards use `border border-border` hairlines (changed from the older `ring-1 ring-foreground/10`) and pad with `py-4 px-4`. Density is moderate — buttons at 40px tall (`h-10`), inputs at 44px tall (`h-11`), badges at 20px tall (`h-5`). Touch-target ergonomics are now web-standard (was 32px, bumped during Stream 1).

**Key Characteristics:**
- **Notion-purple primary** (`oklch(0.55 0.22 285)` ≈ `#7B66E0`) — signature CTA color
- **Inter Variable** font across all surfaces
- 40px-tall buttons, 44px-tall inputs (Notion touch-target spec)
- 8px-rounded buttons (`rounded-md`), 12px-rounded cards (`rounded-lg`)
- 20px pill badges (`rounded-4xl` ≈ full pill via radius scale)
- **Dark mode is the default** as of 2026-05-23. Toggle in the Header (sun/moon icon). Preference persists in `localStorage` under `booking-system:theme`. Light mode remains fully wired via `:root` overrides.
- shadcn `base-nova` style on `@base-ui/react` primitives (not Radix)
- Sidebar + header + main shell, sidebar collapsible
- Density-first: high info per pixel, no marketing-style hero
- Semantic color tokens (success, warning, error) plus link-blue distinct from primary

## Colors

> Source: `frontend/src/index.css`. All colors in OKLCH. Tokens applied via CSS variables exposed under `@theme inline` for Tailwind v4 consumption (`bg-primary`, `text-foreground`, etc.).

### Primary (Notion purple)
- **Primary** (`--primary`): `oklch(0.58 0.27 295)` light / `oklch(0.66 0.26 295)` dark — vivid purple CTA, brighter in dark mode for contrast
- **Primary Foreground** (`--primary-foreground`): `oklch(0.99 0 0)` light / `oklch(0.155 0.002 285)` dark — text on primary surfaces
- **Primary Pressed** (`--primary-pressed`): `oklch(0.50 0.27 295)` light / `oklch(0.58 0.27 295)` dark — deeper purple for pressed/hover state
- **Primary Deep** (`--primary-deep`): `oklch(0.44 0.27 295)` light / `oklch(0.52 0.27 295)` dark — deepest variant for emphasis

### Surface
- **Background** (`--background`): `oklch(1 0 0)` — pure white canvas
- **Card** (`--card`): `oklch(1 0 0)` — same as background
- **Popover** (`--popover`): `oklch(1 0 0)`
- **Secondary / Muted / Accent**: `oklch(0.94–0.965 0.003 285)` — warm-tinted surface tones for nested sections
- **Surface Soft** (`--surface-soft`): `oklch(0.978 0.002 285)` — quietest section divider
- **Sidebar** (`--sidebar`): `oklch(0.982 0.002 285)` — slightly off-canvas for the admin shell

### Hairlines & borders
- **Border / Input** (`--border`, `--input`): `oklch(0.918 0.003 285)` — primary 1px hairline
- **Hairline Soft** (`--hairline-soft`): `oklch(0.952 0.002 285)` — quieter divider
- **Hairline Strong** (`--hairline-strong`): `oklch(0.86 0.005 285)` — stronger input border
- **Ring** (`--ring`): `var(--primary)` — focus ring uses purple

### Text (Notion-aligned ink scale)
- **Foreground** (`--foreground`, `--card-foreground`, `--popover-foreground`): `oklch(0.18 0 0)` — Notion-ink near-black
- **Muted Foreground** (`--muted-foreground`): `oklch(0.48 0.01 285)` — slate, secondary text

### Semantic
- **Destructive / Semantic Error** (`--destructive`, `--semantic-error`): `oklch(0.58 0.22 27)` — warm red
- **Semantic Success** (`--semantic-success`): `oklch(0.62 0.17 145)` — green ≈ `#2DA85C`
- **Semantic Warning** (`--semantic-warning`): `oklch(0.74 0.17 65)` — amber ≈ `#E8A02D`

### Inline links (distinct from primary)
- **Link Blue** (`--link-blue`): `oklch(0.55 0.18 255)` — for inline text links; NOT primary purple
- **Link Blue Pressed** (`--link-blue-pressed`): `oklch(0.48 0.18 255)`

### Charts
- `--chart-1` through `--chart-5`: blue spectrum (`oklch(0.809 0.105 251.813)` → `oklch(0.424 0.199 265.638)`) — for Recharts visualizations on the Analytics page

### Dark mode (now the default)

Activated by default; toggleable from the Header via the sun/moon icon. Choice persists in `localStorage`. Applied synchronously by an inline boot script in `index.html` so there's no flash of light-on-dark on initial paint.

Three-step surface progression — deepest canvas → card (one notch up) → accent/muted (slight elevation) — so cards and modals read as elevated against the canvas:

| Token | Dark value | Notes |
|---|---|---|
| `--background` | `oklch(0.155 0.002 285)` | Deep canvas with a hint of warmth |
| `--card` | `oklch(0.205 0.003 285)` | Card surface, one step up from canvas |
| `--popover` | `oklch(0.225 0.003 285)` | Two steps up for floating layers |
| `--sidebar` | `oklch(0.18 0.002 285)` | Slightly darker than card — admin chrome reads as distinct |
| `--accent` | `oklch(0.33 0.008 285)` | Hover surface for navigation items |
| `--foreground` | `oklch(0.96 0 0)` | Warm off-white text, not pure white |
| `--border` | `oklch(1 0 0 / 12%)` | Translucent white hairline |
| `--hairline-soft` / `-strong` | `oklch(1 0 0 / 7%)` / `oklch(1 0 0 / 22%)` | Three weights for nested sections / form inputs |
| `--primary` | `oklch(0.66 0.26 295)` | Brighter purple, pops on dark bg |
| `--semantic-success` / `-warning` / `-error` | `0.72 / 0.78 / 0.70` lightness | All brightened for dark contrast |
| `--link-blue` | `oklch(0.72 0.18 250)` | Brighter blue for inline links |
| `--chart-*` | re-tuned for dark | Five-step blue-purple ramp |

## Typography

### Font Family
**Inter Variable** (`@fontsource-variable/inter`). Humanist-geometric sans, variable axes. Imported in `index.css`. Single typeface across all UI surfaces.

```css
--font-sans: 'Inter Variable', 'Inter', -apple-system, system-ui, 'Segoe UI', Helvetica, sans-serif;
```

### Hierarchy
There is **no explicit type scale file yet.** Sizes are applied ad-hoc via Tailwind utility classes (`text-sm`, `text-base`, `text-lg`, etc.) on a per-component basis. The implicit scale, observed from `CardTitle`, `Button`, `Input`, headings in pages:

| Use | Class | Equivalent |
|---|---|---|
| Compact body / button label | `text-sm` | 14px / 1.25rem leading |
| Default input text | `text-base md:text-sm` | 16px mobile, 14px desktop |
| Card title | `text-base font-medium` (custom in card.tsx) | 16px / 500 |
| Card description | `text-sm text-muted-foreground` | 14px secondary |
| Small text (table cells, helper) | `text-xs` | 12px |
| Tabs default | `text-sm` (button sm) | 14px |

Page-level headings still use Tailwind size utilities directly (`text-2xl`, `text-3xl`) per-page-author. **An explicit `heading-1..5` token scale remains the most notable typography gap** — see `migration-plan.md` Stream 1 Phase 3.

### Principles (implicit)
- Compact body sizes (sm/base default, not lg)
- 500 weight as the upper bound on most components
- No negative letter-spacing applied globally
- Body leading ≈ 1.5 (Tailwind default)

## Layout

### Spacing System
Tailwind's default 4px scale (`p-1` through `p-24`). No custom spacing tokens.

- Main content area: `p-6` (24px) — note: migration plan recommends `p-8` (32px) for Notion parity but not yet applied
- Card padding: `py-4 px-4` (16px)
- Section gaps between cards: `gap-4` (16px) or `space-y-6` (24px), per-page choice

### Grid & Container
- No global max-width — pages are full-width within the main content area
- Sidebar fixed width when expanded (collapses to icon strip)
- Header fixed height at top

### Whitespace Philosophy
Dense, admin-style. Cards sit close together. No marketing-style breathing room. Padding inside cards is moderate (16px) — tighter than Notion's 24-32px convention.

---

## Elevation & Depth

### Shadows
Tailwind default shadow utilities (`shadow-sm`, `shadow-md`, etc.) used per-page. No project-wide elevation token scale yet.

### Card separation
Primary technique: **`border border-border`** (1px hairline at `oklch(0.918 0.003 285)`). Changed from the older `ring-1 ring-foreground/10` treatment as part of the May 2026 theme swap. Cards don't cast shadows by default.

### Focus
Buttons + inputs use `focus-visible:ring-3 focus-visible:ring-ring/50` — chunky focus halo for keyboard nav. Input focus additionally swaps the border to `border-primary` (purple) on focus.

## Shapes

### Border Radius Scale
Derived from `--radius: 0.5rem` (8px) via `calc()`. Notion-aligned 6/8/12/16/20/24/28 progression:

| Token | Value (rem) | Pixels | Use observed |
|---|---|---|---|
| `--radius-sm` | `calc(0.5 * 0.75)` | 6px | Compact chips |
| `--radius-md` | `0.5rem` | 8px | **Buttons, inputs** |
| `--radius-lg` | `calc(0.5 * 1.5)` | 12px | **Cards, dialogs** |
| `--radius-xl` | `calc(0.5 * 2)` | 16px | Larger feature panels (unused in admin) |
| `--radius-2xl` | `calc(0.5 * 2.5)` | 20px | (Not observed) |
| `--radius-3xl` | `calc(0.5 * 3)` | 24px | (Not observed) |
| `--radius-4xl` | `calc(0.5 * 3.5)` | 28px | Badges (effectively pill at h-5) |

Buttons use `rounded-md` (8px); cards use `rounded-lg` (12px); badges use `rounded-4xl` (pill).

## Components

> Source: `frontend/src/components/ui/*`. Built on `@base-ui/react` primitives, styled with CVA (`class-variance-authority`).

### Buttons

**`Button` (default variant)** — Primary action. Notion-purple CTA.
- `bg-primary text-primary-foreground` (purple with white text)
- Hover / pressed: `hover:bg-primary-pressed`
- `rounded-md` (8px)
- Default size: `h-10 px-4` (40px tall, 16px horizontal padding)
- `text-sm font-medium`

**`Button outline`** — Secondary action.
- `border-hairline-strong bg-background` with hover `bg-muted`
- Same radius/size as default

**`Button secondary`** — Less prominent.
- `bg-secondary text-secondary-foreground`

**`Button ghost`** — Lightest.
- Transparent background, hover `bg-muted`

**`Button destructive`** — Delete/cancel.
- `bg-destructive/10 text-destructive` (10% red tint, red text)

**`Button link`** — Inline link styling.
- `text-link-blue underline-offset-4 hover:underline hover:text-link-blue-pressed`
- Distinct from primary purple — link-blue for inline navigation, purple for CTAs

**Sizes:** `xs` (h-7 / 28px), `sm` (h-8 / 32px), `default` (h-10 / 40px), `lg` (h-11 / 44px); plus `icon` / `icon-xs` / `icon-sm` / `icon-lg` square variants.

### Cards

**`Card`** — Container component.
- `rounded-lg` (12px), `bg-card` (white)
- `border border-border` (1px hairline)
- `py-4` vertical padding, `gap-4` between children
- `text-sm text-card-foreground` (14px body)
- `size="sm"` variant: `py-3` + `gap-3`

**`CardHeader`** — Grid layout for title/description/action.
- `px-4` horizontal padding
- `gap-1` between title and description

**`CardTitle`** — `text-base leading-snug font-medium` (16px / 500). `text-sm` when card is size sm.

**`CardDescription`** — `text-sm text-muted-foreground`.

**`CardContent`** — `px-4` only (no top padding — sits below header's gap).

**`CardFooter`** — `border-t bg-muted/50 p-4`, rounded-b-lg.

### Inputs

**`Input`** — Text field.
- `h-11` (44px), `rounded-md` (8px)
- `border border-hairline-strong` (stronger 1px input border)
- `bg-transparent`, `px-3 py-2`
- `text-base md:text-sm` (16px mobile to avoid iOS zoom, 14px desktop)
- Focus: `focus-visible:border-primary focus-visible:ring-2 focus-visible:ring-primary/20` (purple border + soft halo)

### Badges

**`Badge`** — Status pill.
- `rounded-4xl` (effectively full pill at this height)
- `h-5` (20px), `px-2 py-0.5`
- `text-xs font-medium`
- Variants: `default` (bg-primary now purple), `secondary` (bg-secondary), `destructive` (red tint), `outline` (transparent + border), `ghost`, `link`
- No chromatic-status variants yet (success-green, warning-amber). Tokens exist (`--semantic-success`, `--semantic-warning`) but Badge variants haven't been added — see migration plan Stream 1 Phase 4.

### Tabs, Select, Dialog, Sheet, Switch, Tooltip, Table, Skeleton, Separator, Alert-Dialog, Avatar, Dropdown-Menu, Label, Textarea
All present as shadcn `base-nova` components on `@base-ui/react`. They inherit the new tokens automatically (`bg-primary`, `text-foreground`, `border-border` etc. all resolve to the Notion-themed values).

### Layout

**`AppLayout`** — Persistent shell.
- `flex h-screen overflow-hidden` outer
- Sidebar (collapsible) + flex column with Header + `<main className="flex-1 overflow-y-auto p-6">`
- Single layout used for all authenticated routes
- Wraps everything in `TenantFilterProvider` for super-admin cross-tenant filtering

**`Sidebar`** — Left nav.
- 5 sections (`monitoring`, `data-setup`, `recruitment`, `system`, `super-admin`)
- Lucide icons + label
- Collapsible to icon-only strip
- Active route highlighted via `NavLink`
- Role-gated items hidden via `requiresRole` filter

**`Header`** — Top bar.
- Page title (derived from current pathname via `PAGE_TITLES` map)
- Right-side user/logout controls

## What changed in the May 2026 Notion theme swap

| Before | After |
|---|---|
| `--primary: oklch(0.205 0 0)` (near-black) | `--primary: oklch(0.55 0.22 285)` (Notion purple) |
| Geist Variable font | Inter Variable font |
| Button default `h-8` (32px), `rounded-lg` (10px) | Button default `h-10` (40px), `rounded-md` (8px) |
| Button link uses `text-primary` | Button link uses `text-link-blue` |
| Input `h-8` (32px), `rounded-lg`, generic ring focus | Input `h-11` (44px), `rounded-md`, purple-border focus |
| Card `rounded-xl` (14px), `ring-1 ring-foreground/10` | Card `rounded-lg` (12px), `border border-border` |
| `--radius` base = 10px (0.625rem) | `--radius` base = 8px (0.5rem) |
| No semantic-success, semantic-warning, link-blue tokens | Added all three |
| No hairline-soft / hairline-strong distinction | Three hairline weights now |
| No primary-pressed / primary-deep variants | Added pressed + deep purple variants |

## What's still missing (Stream 1 follow-ups)

- **Explicit typography scale** (`text-heading-1`..`5`, `text-body-md`, etc.) — pages still pick `text-2xl`/`text-3xl` ad-hoc per page-author
- **Chromatic Badge variants** for status (success/warning) — tokens exist, Badge variants don't
- **Per-page typography sweep** — bring page titles to a consistent rhythm
- **Semantic color adoption sweep** — find places using `text-green-600` / `text-yellow-600` ad-hoc and replace with `text-semantic-success` / `text-semantic-warning`
- **Main padding bump** `p-6` → `p-8` (24 → 32px) — recommended in migration plan, not yet applied
