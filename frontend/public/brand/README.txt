mustr — Logo Kit
================
Brand blue: #3D7EB8   Navy: #15293B   Cream: #FAF7F0

Files come in two formats:
  .svg  — vector, scales to any size, ideal for web/print. Recolor by editing the fill values.
  .png  — transparent where applicable. Horizontal = 2400px wide, square = 1200x1200px.

Horizontal lockups
  mustr-primary-blue-transparent   default mark, drop on any light surface
  mustr-blue-on-white              solid white background
  mustr-blue-on-cream              the original look
  mustr-white-on-blue              knockout for blue surfaces
  mustr-white-on-navy              dark UI / footers
  mustr-white-transparent          white mark for any dark background/photo
  mustr-black-transparent          single-colour black (print, stamps, docs)
  mustr-navy-transparent           single-colour navy

Square / icon lockups (avatars, app icons, favicons, social)
  mustr-square-blue-transparent
  mustr-square-white-on-blue
  mustr-square-blue-on-cream

Tip: for favicons, export the square SVG at 32, 180 (Apple touch) and 512px.
